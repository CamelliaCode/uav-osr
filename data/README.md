# 数据集说明

**数据本体不进仓库。** 这里只记录：有哪些数据集、结构长什么样、存在哪。

## 数据集清单

| 数据集 | 模态 | 用途 | 位置 |
| :--- | :--- | :--- | :--- |
| RFUAV（ImageSet） | image | 图像模态训练与评测 | OpenList：待填 |
| RFUAV（原始 IQ） | IQ | IQ 基线 | OpenList：待填 |
| DRFF-R2 | 纯 IQ | IQ 模态训练与评测 | OpenList：待填 |
| 声学数据集 | 声学 | 待定 | 待填 |

## 目录约定

```
<数据根目录>/
├── rfuav/
│   ├── ImageSet/
│   │   ├── train/<类别>/<样本>.png
│   │   └── test/<类别>/<样本>.png
│   └── IQ/
└── drff-r2/
    ├── train/...
    └── test/...
```

## 本地路径

每个人本地路径可以不同，写在**实验目录的 `config.yaml`** 里，不要写死进代码，也不要提交带个人路径的配置。

## 新增数据集

1. 上传到 OpenList，建好目录
2. 在本文件的表格里加一行
3. 在实验 README 里写清楚用了哪个版本、多少样本
