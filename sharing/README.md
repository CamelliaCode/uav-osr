# 每周经验分享

每周一次，每人轮流讲一个「这周学到、别人也用得上」的东西。

**形式**：20 分钟讲 + 10 分钟讨论。一轮讲完再下一轮，不要拖成两小时。

## 什么算一次合格的分享

- 一个**具体的问题** + 一个**可复用的做法**
- 有证据：代码、数字、截图，至少占一样
- 别人看完能自己动手做一遍

反面例子：念一遍论文摘要、贴一堆链接、讲「我们要努力」。

## 不适合放这里的内容

| 内容 | 该放哪 |
| :--- | :--- |
| 会议纪要、任务进度 | 腾讯文档智能表格 |
| 一次实验的完整记录 | `experiments/<实验ID>/` |
| 长篇教程 | 贴链接 + 三句总结就够 |
| 论文全文 | 给 DOI / arXiv 链接 |

## 文件命名

```
sharing/<YYYY-MM-DD>-<主题>.md
sharing/2026-10-24-vit-occlusion.md
```

日期是**分享当天**，不是写稿那天。

## 怎么发一次分享

1. 复制 `_template.md`，按上面的命名新建文件
2. 讲之前填完「一句话结论」和「做法」，讲完补「讨论 / 待办」
3. 提交到 `main`（或开 PR，看你们习惯）
4. 在下面的表格里加一行
