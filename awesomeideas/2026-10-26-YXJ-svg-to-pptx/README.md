# 用 svg2pptx 把图片或 SVG 转成可编辑的 PPT

| 项 | 内容 |
| :--- | :--- |
| 分享人 | 杨兴杰 |
| 日期 | 2026-10-26 |
| 工具 | Codex、svg2pptx 技能、PowerPoint |
| 适用场景 | 论文配图修改、技术架构图重绘、汇报图表整理 |

## 一句话结论

在 Codex 中使用 svg2pptx，可以将符合兼容规范的 SVG 转成由原生对象组成的 PPTX；如果只有 PNG/JPG，可以先重绘为 SVG，再转换，让文字、形状和箭头能够分别编辑。

## 场景

做论文汇报或整理技术方案时，手头往往只有一张架构图或流程图。直接把图片插入 PPT 后，只能整体缩放，无法单独修改文字、颜色或箭头；手工重画又比较耗时。

svg2pptx 的作用是把 SVG 中的图形和文本转换为 PowerPoint 原生对象，方便继续修改和排版。

技能来源：[JamieJustTang/svg2pptx-skill](https://github.com/JamieJustTang/svg2pptx-skill)。以下做法适用于已启用该技能的 Codex。

## 做法

1. **提供原图。** 优先上传保留真实文本和矢量图形的 SVG；如果只有 PNG/JPG，尽量提供文字清晰、分辨率较高的版本。
2. **说明转换要求。** 对 SVG，要求检查兼容性后转换；对 PNG/JPG，要求先识别文字、布局和连接关系，重绘为兼容 SVG，再转换为 PPTX。
3. **打开 PPTX 检查并修改。** 确认文字、形状和箭头可以分别选中，检查文字内容、箭头方向、连接关系和排版，再根据需要调整字体、颜色及位置。遇到组合对象时，可以进一步选中组内元素，或使用“取消组合”。

### 提示词

**已有 SVG 时：**

```text
请使用 svg2pptx 技能，把我上传的 SVG 转成可编辑的 PowerPoint 文件。

要求：
1. 先检查 SVG 兼容性，必要时整理不支持的写法。
2. 保留原有布局、文字内容、配色和箭头连接关系。
3. 文字、形状、线条和箭头使用 PowerPoint 原生对象，能够分别选择和编辑。
4. 保留真实文本，不要将文字转成轮廓或整页图片。
5. 输出 PPTX 文件，并说明转换中无法完整保留的部分。
```

**只有 PNG/JPG 时：**

```text
请把我上传的图片重建成可编辑的 PowerPoint 文件，并使用 svg2pptx 技能完成转换。

要求：
1. 先识别图片中的文字、模块、图标和箭头连接关系，再重绘为兼容的 SVG。
2. 尽量保持原有布局、配色、层级和相对位置。
3. 文字、形状和箭头需要能够分别编辑，不要把整张原图当作最终页面。
4. 对无法辨认的文字或不确定的连接关系，请明确标注，不要自行编造。
5. 复杂图标可以适度简化，但要保留含义，并说明与原图的差异。
6. 输出 PPTX 文件，供我在 PowerPoint 中继续修改。
```

## 效果

两种输入对应的处理过程：

- **SVG：** 兼容性检查 → 必要的整理 → 原生 PPTX。
- **PNG/JPG：** 识别与矢量重绘 → SVG 兼容性检查 → 原生 PPTX。

与直接插入图片相比，转换后的编辑方式如下：

| 修改需求 | 直接插入 PNG/JPG | 重绘并转换为原生 PPTX 后 |
| :--- | :--- | :--- |
| 修改文字 | 无法直接修改图中文字 | 可选中文本修改内容、字体和字号 |
| 调整模块 | 只能整体缩放或裁剪图片 | 可分别调整形状的位置、大小和颜色 |
| 修改箭头 | 无法单独调整 | 可分别选择并调整线条或箭头对象 |
| 继续排版 | 通常需要重新绘图 | 可在 PowerPoint 中继续编辑和组合 |

具体还原程度取决于 SVG 的兼容性，或图片的清晰度与复杂度；转换后仍需逐项检查。

## 踩坑

| 问题 | 处理建议 |
| :--- | :--- |
| 把 PNG/JPG 直接交给转换脚本 | 脚本接收 SVG；图片需要先识别并重绘为 SVG |
| SVG 使用不支持的样式或特效 | 按技能兼容规范整理，优先使用内联样式，避免不支持的 CSS、遮罩和脚本等特性 |
| SVG 中的文字已经变成轮廓 | 需要恢复为真实文本元素，才能作为文字继续编辑 |
| 原图模糊，文字或连接关系不清楚 | 提供更清晰的原图，并人工核对不确定的部分 |
| 复杂图标重绘后细节有差异 | 明确允许简化的范围，重点检查含义、布局和连接关系 |
| 转换后出现字体替换、文字溢出或位置偏差 | 在 PowerPoint 中检查并修正字体、字号、文本框和对齐 |

## 复用建议

- **优先提供 SVG。** 保留真实文本和矢量结构，可以减少图片识别与重绘带来的误差。
- **把“可编辑”说具体。** 在提示词中明确要求文字、形状和箭头分别可选、可改，并保留真实文本。
- **复杂图先核对结构。** 对模块较多的架构图，先确认文字和连接关系，再细化配色、图标和排版。
- **交付前检查关键细节。** 重点核对文字、箭头方向、连接关系、字体替换和排版。
- **使用 PPTX 格式。** 输出为现代 PowerPoint 的 `.pptx`，方便后续编辑。
