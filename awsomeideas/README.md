# 每周经验分享 · awsomeideas

每周一次，每人轮流分享一个「AI 使用小技巧」。

**形式**：20 分钟讲 + 10 分钟讨论。一轮讲完再下一轮，不要拖成两小时。

## 什么算一次合格的分享

- 一个具体场景 + 一段**能直接复制**的提示词
- 有前后对比（截图、数字都行）
- 别人看完能立刻用上

反面例子：念一遍论文摘要、贴一堆链接、讲「我们要努力」。

## 不适合放这里的内容

| 内容 | 该放哪 |
| :--- | :--- |
| 会议纪要、任务进度 | 腾讯文档智能表格 |
| 一次实验的完整记录 | `src/<方向>/<实验ID>/` |
| 长篇教程 | 贴链接 + 三句总结就够 |
| 论文全文 | 给 DOI / arXiv 链接 |

## 目录规范：一次分享 = 一个文件夹

```
awsomeideas/
├── _template/                       # 模板，复制这个
│   └── README.md
└── 2026-10-24-jianghan-ai-paper/    # 日期-姓名-主题
    ├── README.md                    # 正文
    └── images/                      # 这篇用到的截图
        ├── 01-before.png
        └── 02-after.png
```

**为什么用文件夹，而不是单个 md**：截图要跟着正文走。单文件的话图片只能散在别处，一搬就断链。

**命名**：`YYYY-MM-DD-姓名-主题`。日期写分享当天；姓名用**拼音**——路径里出现中文，链接会变成 `%E6%B1%9F%E6%B6%B5` 这种乱码，发给人不好看。

同一主题第二个人讲，就再建一个文件夹，不用改旧的。

## 图片怎么插

1. 截图存成 png，放进这篇的 `images/`，**按顺序编号**：`01-before.png`、`02-after.png`
2. 在 README.md 里用**相对路径**引用：

```markdown
![前后对比](images/01-before.png)
```

3. 建议宽度 ≤ 1600px、单张 ≤ 500KB。GitHub 单文件上限 100MB，但仓库胖了以后 clone 会很慢。

## 图片怎么上传（三条路，选一条）

**A. 网页上传（不用装 git，最稳）**

1. 打开仓库里对应的文件夹
2. 右上 **Add file → Upload files**，把图片拖进去 → Commit changes
3. 再点开 `README.md`，铅笔图标编辑，写上 `![说明](images/01-before.png)`

**B. 直接粘贴（最快）**

在网页上编辑 `README.md` 时，**直接把截图 Ctrl+V 粘进编辑框**，GitHub 会自动上传并把链接插到光标处。适合边写边贴。

**C. 本地 git**

```powershell
git clone https://github.com/CamelliaCode/uav-osr.git
# 放文件、写 md
git add . ; git commit -m "add 2026-10-24 ai tips" ; git push
```
