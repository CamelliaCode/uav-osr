# 实验记录

一次实验 = 一个目录，目录名就是实验 ID。

## 实验 ID

```
exp-<日期>-<方法>-<数据集>-<当天序号>
exp-20261019-vit-rfuav-01
```

同一个 ID 在四个地方保持一致：

- 本仓库的 `experiments/<实验ID>/`
- 腾讯文档任务表的「方案/产出」列
- OpenList 上的产物目录
- 服务器上的日志文件名

## 怎么开一次新实验

1. 把 `_template/` 复制成 `experiments/<实验ID>/`（网页上也能直接复制文件）
2. 改 `README.md` 的「目的」和「改动点」
3. 改 `config.yaml` 里的数据路径和超参
4. 跑完把指标填进「结果」，权重/日志链接填进「产物」
5. 去腾讯文档把对应任务的状态改成「已完成」

## 写什么、不写什么

| 写 | 不写 |
| :--- | :--- |
| 这次和上次比改了什么 | 完整代码（代码不在本仓库） |
| 关键指标 2–3 个 | 整张结果表（放产物里） |
| 结论：有效 / 无效 / 待定 | 一堆中间过程日志 |
| 踩过的坑 | |

## 一次实验最少要留四样

1. 一句话目的
2. 完整配置（`config.yaml`）
3. 2–3 个关键指标
4. 一句结论
