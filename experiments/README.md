# 实验记录

一次实验 = 一个目录，目录名就是实验 ID。

## 实验 ID 规范

```
exp-<日期>-<方法>-<数据集>-<当天序号>
exp-20261019-vit-rfuav-01
```

同一天同一个方法第 2 次跑就写 `-02`。这个 ID 在四个地方保持一致：

- 本仓库的 `experiments/<实验ID>/`
- 腾讯文档任务表的「方案/产出」列
- OpenList 上的产物目录
- 训练日志的文件名

## 怎么开一次新实验

```bash
cp -r experiments/_template experiments/exp-20261019-vit-rfuav-01
```

然后：

1. 改 `README.md` 里的「目的」和「改动点」
2. 改 `config.yaml` 里的路径和超参
3. 跑完把指标填进 README 的「结果」
4. 权重和日志传 OpenList，链接写进 README 的「产物」

## 什么该写、什么不该写

| 写 | 不写 |
| :--- | :--- |
| 这次和上次比改了什么 | 完整代码（代码在 src/） |
| 关键指标 2–3 个 | 整张结果表（放产物里） |
| 结论：有效 / 无效 / 待定 | 一堆中间过程日志 |
| 踩过的坑（下次少走弯路） | |
